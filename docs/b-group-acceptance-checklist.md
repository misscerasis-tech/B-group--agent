# B 组工作助手验收清单

本清单用于验收 `feature/b-group-working-assistant`。当前目标不是静态演示页，而是本地可运行、可保存、可回滚的 AI 内容增长工作助手底座。

## 启动前

- 已安装 Node.js、pnpm 或可使用 `npx pnpm@10.13.1`。
- 已安装并启动 Docker Desktop。
- 已复制 `.env.example` 为 `.env`，并填写本地 PostgreSQL 用户名、密码和 `DATABASE_URL`。
- 已执行数据库迁移和 seed。

## 推荐命令

```bash
npx pnpm@10.13.1 install
npx pnpm@10.13.1 run doctor
npx pnpm@10.13.1 run docker:up
npx pnpm@10.13.1 run db:migrate
npx pnpm@10.13.1 run db:seed
npx pnpm@10.13.1 run dev:b
```

打开：

```text
http://127.0.0.1:3002/b-agent
```

如果 3002 已被其他小组服务占用，使用：

```bash
npx pnpm@10.13.1 exec next dev -p 3003
```

并打开 `http://127.0.0.1:3003/b-agent`。

健康检查：

```text
http://127.0.0.1:3002/setup
http://127.0.0.1:3002/api/health
```

`/setup` 应显示中文诊断和下一步建议；`/api/health` 返回 `database.status: "ok"` 后再验收页面。如果返回 `unavailable`，先检查 Docker PostgreSQL 和 `.env`。

## 必验流程

- 顶部可以在 `演示增长团队` 与 `欧洲增长演示团队` 之间切换，项目和产品数据不会串到另一个 Workspace。
- 顶部可以创建新的 Workspace，创建后自动切换，新 Workspace 初始为空数据。
- 今日工作台可以看到“今日行动队列”，待确认 Agent 变更、审核任务和未审核素材应排在普通计划之前。
- 今日工作台可以看到“项目就绪度”，并展示每个项目的评分、状态、缺口摘要和下一步动作。
- 项目详情页可以看到完整体检清单，覆盖产品关联、产品事实、正式策略、计划、素材包、真实视觉素材、审核、复盘和提醒。
- 项目详情页点击“生成缺口提醒”后，应在提醒中心看到对应项目提醒；再次点击不会重复创建同标题开放提醒。
- `/b-agent` 可以看到左侧中文对话和右侧结构化工作台。
- 项目中心可以用一段中文 Brief 一次创建项目、产品、产品事实、策略草案和启动对话，并跳转到新项目的 `/b-agent` 工作台。
- 在 `/b-agent` 输入：`巴西不做 LinkedIn，新增 TikTok，下个月每周生成一次素材包。`
- 策略未确认时，明确指令可直接写入策略和变更日志。
- 在 `/b-agent` 输入：`不要学生用户，新增礼品购买者，本月不做小抽奖。` 可以识别客群和内容方向调整。
- 在 `/b-agent` 输入：`暂停这个项目，新增 TikTok。` 可以识别项目状态变更并写入 Project 表。
- 在 `/b-agent` 输入：`提醒我提前确认巴西抽奖奖品和活动规则。` 可以创建当前项目提醒。
- 在 `/b-agent` 输入：`请生成首月计划和第一份素材包结构。` 可以创建首月计划、素材包结构、提醒和变更日志；已有计划时不会重复创建。
- 在 `/b-agent` 输入：`记录 2026-07 第3周 TikTok 曝光10000 点击600 转化24 花费1234.56 元。` 可以写入数据复盘指标和变更日志。
- 确认正式策略后，再提交策略修改会进入待确认队列；可以确认应用或拒绝。确认后创建新的策略版本，拒绝后正式策略保持不变。
- 产品大脑可以从产品说明或补充资料提取事实；已确认事实不会被静默覆盖。
- 产品详情页可以从已关联的 TXT、MD、CSV、JSON 产品资料 Asset 提取待确认事实；PDF/DOCX 资料不会被本地文本提取器误读。
- 创建或编辑项目/产品、关联产品、生成或确认产品事实后，最近变更中可以看到对应记录。
- 素材库上传素材时，会校验 20MB 大小限制、文件格式和当前 Workspace 下的项目/产品关联；上传后自动出现在审核中心，可下载原始文件，素材可审核通过或拒绝，且素材库直接处理会同步关闭对应审核任务。
- 素材库中至少一张真实产品图和一个官方 Logo 审核通过后，可以生成本地分层 SVG 模板海报，任务来源素材为这两个已审核 Asset，生成结果可从素材库下载。
- 内容日历可以手动新增计划项，看到首月计划截止日期，并把计划项设为可执行、需审核或已完成。
- 素材包中心可以手动创建素材包结构、把文件项关联到已审核素材、推进文件项状态、提交 Web 审核，并下载包含基础 PDF、XLSX、DOCX、TXT、关联素材和 manifest 的本地 ZIP 可交付文件包。
- 素材包中心可以看到“可交付性检查”，ZIP 内应包含 `00-交付检查.txt`；若只关联生成图而没有真实产品图和 Logo，应显示阻塞。
- 项目详情和 `/b-agent` 可以下载项目工作台 JSON 快照，且快照只包含当前 Workspace 下的数据。
- 审核中心可以生成审核任务，并将通过/要求修改写回业务对象；误生成任务可以取消。
- 提醒中心可以生成主动提醒，并标记完成或忽略。
- 提醒中心可以手动创建 Workspace 或项目级提醒，并在卡片上显示级别和截止日期。
- 数据复盘可以手动录入曝光、点击、转化和花费，并在页面聚合展示 CTR、点击转化率和单次转化成本；点击不能大于曝光，转化不能大于点击。
- 数据复盘可以粘贴 CSV 或从表格复制的多行指标数据批量导入，导入结果写入当前 Workspace 项目和变更日志。
- 录入表现数据后，再点击提醒中心“生成主动提醒”，系统可以基于低 CTR、有点击无转化或有花费无转化生成数据风险提醒。
- 数据复盘可以下载 Workspace 复盘 JSON 快照，快照只包含当前 Workspace 的指标、建议、近期表现和最近变更。
- 集成设置可以保存飞书占位连接、测试占位连接、停用旧连接、记录迁移说明；不需要真实飞书授权，且不保存密钥。
- Seed 后素材库会有可下载的 SVG 示例产品图、Logo 和模板海报，演示素材包中的海报文件项已关联到生成图。

DATABASE_URL="postgresql://placeholder:placeholder@localhost:5432/placeholder?schema=public" npx pnpm@10.13.1 run build

## 不在本阶段验收

- 真实 GPT 调用。
- 真实飞书 API 连接。
- 真实社媒平台数据 API。
- 正式精排 PDF、复杂 DOCX/XLSX 和 PNG 海报成品生成。
- AI 重绘产品图或生成产品主体。
