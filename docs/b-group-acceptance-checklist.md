# B 组工作助手验收清单

本清单用于验收 `feature/b-group-working-assistant`。当前目标不是静态演示页，而是本地可运行、可保存、可回滚的 AI 内容增长工作助手底座。

## 启动前

- 已安装 Node.js、pnpm 或可使用 `npx pnpm@10.13.1`。
- 已安装并启动 Docker Desktop。
- 已复制 `.env.example` 为 `.env`，并填写本地 PostgreSQL 用户名、密码和 `DATABASE_URL`。
- 已执行数据库迁移和 seed。

## 推荐命令

```bash
npx pnpm@10.13.1 install
npx pnpm@10.13.1 run doctor
npx pnpm@10.13.1 run docker:up
npx pnpm@10.13.1 run db:migrate
npx pnpm@10.13.1 run db:seed
npx pnpm@10.13.1 run dev:b
```

`doctor` 会检查当前目录、Git 状态、`.env`、Docker、Docker Compose、Node.js、pnpm 和 `3002` 端口。如果 `3002` 已被其他小组服务占用，它会显示占用进程，并建议一个可用端口。

打开：

```text
http://127.0.0.1:3002/b-agent
```

如果 3002 已被其他小组服务占用，使用：

```bash
npx pnpm@10.13.1 exec next dev -p 3003
```

如果 `doctor` 建议的是其他端口，把命令里的 `3003` 换成诊断结果里的端口，并打开对应的 `/b-agent`，例如 `http://127.0.0.1:3003/b-agent`。

健康检查：

```text
http://127.0.0.1:3002/setup
http://127.0.0.1:3002/api/health
```

`/setup` 应显示中文诊断和下一步建议；`/api/health` 返回 `database.status: "ok"` 后再验收页面。如果返回 `unavailable`，先检查 Docker PostgreSQL 和 `.env`。

Web 启动后可运行冒烟检查：

```bash
npx pnpm@10.13.1 run smoke
```

冒烟脚本会兼容 `/b-agent` 在数据库正常和诊断降级状态下的不同中文标题。

如果使用 3003：

```bash
npx pnpm@10.13.1 run smoke -- --url http://127.0.0.1:3003
```

## 必验流程

- 顶部可以在 `演示增长团队` 与 `欧洲增长演示团队` 之间切换，项目和产品数据不会串到另一个 Workspace。
- 顶部可以创建新的 Workspace，创建后自动切换，新 Workspace 初始为空数据。
- 今日工作台顶部可以看到 Agent 工作简报，能把素材包、近期计划、开放提醒和渠道表现汇总成重点进展、风险提醒和建议动作。
- 今日工作台可以看到“今日行动队列”，待确认 Agent 变更、审核任务和未审核素材应排在普通计划之前。
- 今日工作台可以看到“项目就绪度”，并展示每个项目的评分、状态、缺口摘要和下一步动作。
- 今日工作台点击“导出 Workspace 备份”可以下载 JSON，内容只包含当前 Workspace，且疑似密钥字段应被屏蔽。
- 下载后的 Workspace 备份 JSON 可以用 `npx pnpm@10.13.1 run backup:validate -- <文件路径>` 校验 schema、计数、敏感字段脱敏和 Workspace 归属。
- 项目详情页可以看到完整体检清单，覆盖产品关联、产品事实、正式策略、计划、素材包、真实视觉素材、审核、复盘和提醒。
- 项目详情页点击“生成缺口提醒”后，应在提醒中心看到对应项目提醒；再次点击不会重复创建同标题开放提醒。
- `/b-agent` 可以看到左侧中文对话和右侧结构化工作台。
- `/b-agent` 右侧工作台顶部应显示“项目体检”，包含项目就绪度分数、状态和最多 4 个下一步动作。
- 项目中心可以用一段中文 Brief 一次创建项目、产品、产品事实、策略草案和启动对话，并跳转到新项目的 `/b-agent` 工作台。
- 空 Workspace 打开 `/b-agent` 时，可以直接用中文 Brief 启动第一个 B 组项目。
- 已有项目时，`/b-agent` 左侧“启动新项目”可以继续用中文 Brief 创建新项目，提交后应自动切换到新项目工作台。
- 在已有项目的 `/b-agent` 指令框输入：`创建一个日本母婴礼赠内容增长项目，产品名称：Aurora Cup 迷你保温杯，主推日本市场，新增 TikTok，每周生成一次素材包。` 应创建新项目、新产品、待确认事实和策略草案，并自动切换到新项目。
- 在 `/b-agent` 输入：`切换到蒙古项目工作台。` 应只在当前 Workspace 内匹配项目并跳转到蒙古项目；输入不存在的项目关键词时应显示未执行，不应修改任何业务数据。
- 在 `/b-agent` 输入：`帮我看看这个项目现在怎么样，下一步该做什么？` 应返回项目简报，包含就绪度、策略、近期计划、最新素材包、开放提醒和建议动作，且不修改业务数据。
- 在 `/b-agent` 输入：`今天我该优先做什么？` 应返回 Workspace 今日工作简报，包含近期计划、素材包、开放提醒、渠道表现、风险和下一步动作，且不修改业务数据。
- 在 `/b-agent` 输入：`新增产品：Aurora Cup 车载保温杯，600ml，不锈钢，适合通勤车主和礼品购买者。` 应给当前项目新增并关联产品，并在产品大脑看到待确认事实。
- 在 `/b-agent` 输入：`巴西不做 LinkedIn，新增 TikTok，下个月每周生成一次素材包。`
- 策略未确认时，明确指令可直接写入策略和变更日志。
- 在完整策略草案下输入：`确认当前策略为正式策略。` 应把策略状态改为正式策略并写入变更日志；如果策略缺少目标市场、平台渠道或内容方向，应显示未执行。
- 在 `/b-agent` 输入：`不要学生用户，新增礼品购买者，本月不做小抽奖。` 可以识别客群和内容方向调整。
- 在 `/b-agent` 输入：`暂停这个项目，新增 TikTok。` 可以识别项目状态变更并写入 Project 表。
- 在 `/b-agent` 输入：`新增产品事实：卖点=24小时保温。` 可以给当前项目关联产品新增需复核事实，并在产品大脑看到该事实。
- 在 `/b-agent` 输入：`把容量改成 600ml。` 可以修改当前项目关联产品中匹配的规格参数，并把该事实转为需复核。
- 在 `/b-agent` 输入：`提醒我提前确认巴西抽奖奖品和活动规则。` 可以创建当前项目提醒。
- 在 `/b-agent` 输入：`把抽奖规则提醒标记完成。` 可以把当前项目内匹配的开放提醒设为完成；匹配不到时应失败且不误改提醒。
- 在 `/b-agent` 输入：`请生成首月计划和第一份素材包结构。` 可以创建首月计划、素材包结构、提醒和变更日志；已有计划时不会重复创建。
- 在 `/b-agent` 输入：`记录 2026-07 第3周 TikTok 曝光10000 点击600 转化24 花费1234.56 元。` 可以写入数据复盘指标和变更日志。
- 在 `/b-agent` 粘贴 `批量导入指标：` 加多行 CSV 或表格文本，例如 `周期,渠道,曝光,点击,转化,花费,备注` 后接 TikTok/Instagram 两行数据，可以一次写入多条当前项目指标和变更日志。
- 在 `/b-agent` 输入：`第2周 TikTok 做一条开箱短视频，主题新品认知，交付短视频脚本，截止 2026-08-07，可执行。` 可以新增内容日历计划项和变更日志。
- 在 `/b-agent` 粘贴 `批量导入内容计划：` 加多行 CSV 或表格文本，例如 `周次,渠道,主题,标题,交付物,截止日期,状态` 后接 TikTok/Instagram 两行排期，可以一次写入多条当前项目内容计划和变更日志。
- 在 `/b-agent` 输入：`第2周 TikTok 开箱短视频已完成。` 可以把当前项目内匹配的未完成计划项设为完成，并写入变更日志。
- 在 `/b-agent` 输入：`为 2026-08 第1周创建 TikTok 素材包。` 可以创建指定周期素材包结构，并在素材包中心看到 11 项默认文件清单。
- 在 `/b-agent` 输入：`提交最新素材包审核。` 可以把当前项目最近素材包设为需审核，并在审核中心看到对应待审核任务。
- 在 `/b-agent` 输入：`最新素材包审核通过。` 可以处理当前项目下已有待审核素材包任务，并把素材包设为已通过；没有待审核任务时应失败且不误改。
- 确认正式策略后，再提交策略修改会进入待确认队列；可以确认应用或拒绝。确认后创建新的策略版本，拒绝后正式策略保持不变。
- 修改正式策略时，若删除唯一渠道、删除内容日历仍使用的渠道、清空内容方向、降低素材包频率或暂停/归档项目，待确认操作中应出现风险提示。
- 产品大脑可以从产品说明或补充资料提取事实；通过中文指令校准事实后会转为需复核，已确认事实不会被规则提取静默覆盖。
- 产品详情页可以从已关联的 TXT、MD、CSV、JSON、DOCX 和文本型 PDF 产品资料 Asset 提取待确认事实；扫描件 PDF 不会被误读，需先 OCR 或整理成 Brief。
- 创建或编辑项目/产品、关联产品、生成或确认产品事实后，最近变更中可以看到对应记录。
- 素材库上传素材时，会校验 20MB 大小限制、文件格式和当前 Workspace 下的项目/产品关联；上传后自动出现在审核中心，可下载原始文件，素材可审核通过或拒绝，且素材库直接处理会同步关闭对应审核任务。
- 素材库中至少一张真实产品图和一个官方 Logo 审核通过后，可以生成本地分层 SVG 模板海报，任务来源素材为这两个已审核 Asset，生成结果可从素材库下载。
- 内容日历可以手动新增计划项，看到首月计划截止日期，并把计划项设为可执行、需审核或已完成。
- 素材包中心可以手动创建素材包结构、把文件项关联到已审核素材、推进文件项状态、提交 Web 审核，并下载包含基础 PDF、XLSX、DOCX、TXT、关联素材、人工审核清单和 manifest 的本地 ZIP 可交付文件包。
- 素材包中心可以看到“可交付性检查”，ZIP 内应包含 `00-交付检查.txt`；若只关联生成图而没有真实产品图和 Logo，应显示阻塞。
- `/b-agent` 的素材包预览也应显示“交付体检”，并列出文件生成、文件审核、真实产品图、官方 Logo 和素材包审核的状态与下一步动作。
- 项目详情和 `/b-agent` 可以下载项目工作台 JSON 快照，且快照只包含当前 Workspace 下的数据。
- 审核中心可以生成审核任务，并将通过/要求修改写回业务对象；误生成任务可以取消。
- 提醒中心可以生成主动提醒，并标记完成或忽略。
- 提醒中心可以手动创建 Workspace 或项目级提醒，并在卡片上显示级别和截止日期。
- 数据复盘可以手动录入曝光、点击、转化和花费，并在页面聚合展示 CTR、点击转化率和单次转化成本；点击不能大于曝光，转化不能大于点击。
- 数据复盘可以粘贴 CSV 或从表格复制的多行指标数据批量导入，导入结果写入当前 Workspace 项目和变更日志。
- 录入表现数据后，再点击提醒中心“生成主动提醒”，系统可以基于低 CTR、有点击无转化或有花费无转化生成数据风险提醒。
- 数据复盘可以下载 Workspace 复盘 JSON 快照，快照只包含当前 Workspace 的指标、建议、近期表现和最近变更。
- 集成设置可以保存飞书占位连接、测试占位连接、停用旧连接、记录迁移说明；不需要真实飞书授权，且不保存密钥。
- Seed 后素材库会有可下载的 SVG 示例产品图、Logo 和模板海报，演示素材包中的海报文件项已关联到生成图。
- Seed 后主 Workspace 会同时有巴西完整项目和蒙古缺口项目；蒙古项目应在项目就绪度和素材包可交付性检查中显示阻塞项。

## 技术验收

```bash
npx pnpm@10.13.1 exec prisma validate
npx pnpm@10.13.1 run lint
npx pnpm@10.13.1 run typecheck
npx pnpm@10.13.1 run test
DATABASE_URL="postgresql://placeholder:placeholder@localhost:5432/placeholder?schema=public" npx pnpm@10.13.1 run build
```

## 不在本阶段验收

- 真实 GPT 调用。
- 真实飞书 API 连接。
- 真实社媒平台数据 API。
- 正式精排 PDF、复杂 DOCX/XLSX 和 PNG 海报成品生成。
- AI 重绘产品图或生成产品主体。
