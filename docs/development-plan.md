# 开发计划

## 总体策略

开发采用“稳定主线 + 阶段分支 + 可回滚 Tag”的方式推进。

- `main` 只保存可运行、可测试、可演示版本。
- 每个阶段从 `main` 创建独立分支。
- 阶段完成后运行测试、更新文档和 `CHANGELOG.md`，再提交。
- 确认可运行后再合并回 `main` 并打 Tag。

## 阶段 0：仓库初始化

建议 Tag：`v0.0.1-initial`

目标：

- 创建独立项目目录。
- 初始化 Git 仓库和 `main` 分支。
- 创建基础文件和规划文档。
- 不启动产品功能开发。

验收：

- 仓库是独立 Git 仓库。
- `main` 分支存在。
- 基础文件齐全。
- 初始化 commit 和 Tag 存在。

## 阶段 1：Foundation 最小系统骨架

建议分支：`feature/phase-1-foundation`

建议 Tag：`v0.1.0-foundation`

目标：

- 搭建 Next.js + TypeScript Web 应用。
- 建立中文基础界面框架。
- 建立数据库迁移体系。
- 建立 Workspace / User / Project / Product 的最小数据模型。
- 建立测试、格式化和基础 CI 约束。
- 提供本地启动说明。
- 预留图片生成供应商抽象和 V1 模板化合成图层策略。

不做：

- 不接入真实飞书。
- 不接入真实 AI 内容生成。
- 不做完整素材生成。
- 不做正式海报生成。
- 不做第三方登录。

最小可测试范围：

- 可以本地启动 Web。
- 可以看到中文首页或工作台。
- 可以创建 Workspace、项目和产品的最小记录。
- 数据库结构通过迁移文件创建。
- 基础测试可以运行并通过。
- 所有核心业务查询在服务端按当前 Workspace 限制。

本阶段页面范围：

- 今日工作台。
- 项目中心。
- 产品大脑。
- 内容日历、素材包、审核中心、提醒中心、数据复盘、集成设置占位。

## B 组阶段 1.5：Working Assistant 本地可用助手

建议分支：`feature/b-group-working-assistant`

建议 Tag：验收通过后再决定，例如 `v0.1.5-b-working-assistant`。

目标：

- 把 `/b-agent` 从静态演示模板升级为数据库驱动的工作台。
- 建立 Agent 对话、结构化操作、策略、计划、素材包、提醒和变更日志模型。
- 先用 `AgentTextProvider` 抽象承载中文指令处理，默认实现为本地规则型 `local-rule`，不接真实 GPT。
- 支持策略草案直接应用安全变更，正式策略变更必须二次确认。
- 产品大脑支持结构化产品事实生成、补充和确认。
- 素材库支持上传真实产品图、官方 Logo、资料和参考图。
- 图片生成供应商配置和任务模型先落库，不调用真实模型。
- 集成设置支持飞书占位连接、停用旧连接和保存迁移记录。
- 内容日历、素材包中心、审核中心、提醒中心读取真实 Workspace 数据。
- 素材包中心支持本地 ZIP 可交付文件包导出，先输出交付检查、基础 PDF、XLSX、DOCX、TXT、关联素材和 manifest。
- 审核中心支持生成和处理 Web 系统内审核任务，飞书后续仅作为外部入口。
- 提醒中心支持基于项目数据主动生成提醒，也支持人工创建 Workspace 或项目级提醒，并可在 Web 内完成或忽略。
- 数据复盘支持手动录入渠道表现，为未来平台 API 自动回流预留落点。

不做：

- 不接真实 GPT。
- 不接飞书。
- 不生成正式精排 PDF、复杂 DOCX/XLSX 或 PNG 海报成品。
- 不生成正式海报图片。
- 不接外部社媒数据。

验收：

- Seed 后可以打开 `/b-agent` 看到真实项目数据。
- `/setup` 可以显示中文本地运行诊断，帮助确认数据库、环境变量和 AI Provider 降级状态。
- Seed 后素材库包含可下载的 SVG 示例产品图、Logo 和模板海报，演示素材包已关联海报 Asset。
- Seed 后主 Workspace 同时包含一个较完整项目和一个缺口项目，用于验收项目体检、缺口提醒和素材包阻塞状态。
- Seed 后可以通过顶部 Workspace 切换验证不同 Workspace 的项目和产品隔离。
- 今日工作台可以基于待确认变更、审核、素材、策略、素材包和近期计划生成行动队列。
- 今日工作台和项目详情可以基于产品关联、产品事实、正式策略、计划、素材包、真实视觉素材、审核、复盘和提醒生成项目就绪度体检。
- 今日工作台可以导出当前 Workspace 安全备份 JSON，用于演示前备份和回滚核对。
- 今日工作台可以基于素材包、近期计划、开放提醒和渠道表现生成 Agent 工作简报。
- Web 启动后可以运行 `npx pnpm@10.13.1 run smoke`，快速检查 `/setup`、`/api/health`、`/b-agent` 和 `/dashboard` 是否可访问。
- 项目详情可以把体检缺口生成项目提醒，并避免重复创建同标题开放提醒。
- 顶部 Workspace 区域可以创建新的 Workspace，并自动切换过去。
- 输入“巴西不做 LinkedIn，新增 TikTok，下个月每周生成一次素材包。”可以生成结构化操作并写入策略。
- 输入“不要学生用户，新增礼品购买者，本月不做小抽奖。”可以生成客群和内容方向调整。
- 输入“暂停这个项目，新增 TikTok。”可以生成项目状态和渠道调整，并写入对应业务表。
- 输入“请根据产品事实推荐一版巴西首月增长策略。”可以基于当前项目关联产品事实生成策略推荐草案；已有正式策略时创建新草案版本，等待人工确认。
- 输入“新增产品事实：卖点=24小时保温。”可以给当前项目关联产品新增需复核事实，并写入变更日志。
- 输入“请从产品资料提取产品事实：智能温显保温杯，500ml，不锈钢，适合通勤和健身，24小时保温。”可以批量生成待复核产品事实；已确认事实不会被覆盖。
- 输入“确认当前项目所有产品事实。”可以把当前项目关联产品下的草稿/待复核事实确认，确认范围不会越过当前 Workspace 和当前项目。
- 输入“提醒我 2026-08-07 前确认巴西抽奖奖品和活动规则。”可以在当前项目下创建带截止日期的提醒并写入变更日志。
- 输入“把抽奖规则提醒标记完成。”可以完成当前项目下匹配的开放提醒；匹配不到时不修改业务数据。
- 输入“忽略抽奖规则提醒。”可以把当前项目下匹配的开放提醒标记为已忽略；匹配不到时不修改业务数据。
- 输入“把抽奖规则提醒截止日期改到 2026-08-10。”可以调整当前项目下匹配的开放提醒截止日期。
- 输入“把项目体检缺口生成提醒。”可以把项目就绪度体检的下一步动作转换为提醒，并避免重复创建同标题开放提醒。
- 输入“请生成首月计划和第一份素材包结构。”可以通过 Agent 对话创建首月计划、素材包结构和配套提醒；已有计划时不会重复创建。
- 输入“记录 2026-07 第3周 TikTok 曝光10000 点击600 转化24 花费1234.56 元。”可以通过 Agent 对话写入数据复盘指标。
- 输入“把数据复盘风险生成提醒。”可以把当前项目的低点击率、无转化或花费无转化风险转成提醒；当前项目没有复盘指标时不会写入业务数据。
- 输入“第2周 TikTok 做一条开箱短视频，主题新品认知，交付短视频脚本，截止 2026-08-07，可执行。”可以通过 Agent 对话新增内容日历计划项。
- 输入“第2周 TikTok 开箱短视频标记为需审核。”可以把当前项目下匹配的内容计划改为需审核；也支持改为可执行或草稿。
- 输入“第2周 TikTok 开箱短视频截止日期改到 2026-08-10。”可以调整当前项目下匹配的内容计划截止日期，并写入变更日志。
- 输入“第2周 TikTok 开箱短视频已完成。”可以完成当前项目下匹配的未完成内容计划，并写入变更日志。
- 输入“把内容日历缺口生成提醒。”可以把当前策略中没有排期的渠道、首月没有计划的周次转成项目提醒，并避免重复提醒。
- 输入“为 2026-08 第1周创建 TikTok 素材包。”可以通过 Agent 对话创建指定周期素材包结构，并自动生成 V1 默认 11 项文件清单。
- 输入“归档最新素材包。”可以把当前项目下匹配的素材包改为已归档；输入“恢复最新素材包为草稿。”可以恢复为草稿状态。
- 输入“把最新素材包可交付性缺口生成提醒。”可以把素材包阻塞项转换为提醒，优先覆盖文件未生成、缺少真实产品图和缺少官方 Logo。
- 输入“把最新素材包全部文件标记为已生成。”可以在用户明确确认后批量推进文件项状态，并同步素材包整体状态；这只是状态推进，不代表系统伪造真实外部素材。
- 输入“把最新模板海报关联到最新素材包。”可以把当前项目已审核生成图关联到素材包海报文件项；找不到已审核模板海报或海报文件项时不会写入业务数据。
- 输入“提交最新素材包审核。”可以通过 Agent 对话提交当前项目素材包审核，并创建 Web-first 审核任务。
- 输入“最新素材包审核通过。”或“最新素材包要求修改。”可以通过 Agent 对话处理当前项目下已有待审核素材包任务。
- 输入“产品事实审核通过。”、“策略草案要求修改。”或“Logo 素材审核不通过，要求修改。”可以通过 Agent 对话处理审核中心任务，并同步写回产品事实、策略草案或素材状态。
- 输入“取消最新素材包审核任务。”可以取消当前项目下匹配的待审核任务，并保留被审核业务对象原状态。
- 输入“补齐当前项目审核中心任务。”可以为当前项目的策略草案、素材包、待审核素材和待复核产品事实补齐审核任务。
- 修改正式策略时，Agent 会在待确认操作里提示删除唯一渠道、删除仍被内容日历使用的渠道、清空内容方向、降低素材包频率和暂停/归档项目等风险。
- 项目中心可以通过中文 Brief 启动项目，并自动创建项目、产品、关联、待确认事实、策略草案、对话和变更日志。
- 确认正式策略后，再提交修改会进入待确认队列，并支持确认应用或拒绝。
- 确认后的策略变更会创建新版本，并可在 `/b-agent` 查看策略版本历史。
- 产品详情页可以从产品说明或补充资料生成、手动新增和确认产品事实。
- 产品详情页可以从已关联的文本型产品资料 Asset 提取待确认事实，PDF/DOCX 解析留到后续文件处理阶段。
- 项目和产品的创建、编辑、关联产品、事实生成与确认会写入变更日志。
- 素材库可以上传和下载素材，校验文件大小、格式、下载路径和 Workspace 关联，自动创建审核任务，并标记审核通过或拒绝；素材库直接处理后审核中心任务同步更新。
- 素材库可以用已审核真实产品图和官方 Logo 生成本地分层 SVG 模板海报，并将结果保存为 Asset。
- Asset 和 ImageGenerationJob 记录均按 Workspace 隔离。
- 飞书占位连接、占位测试和迁移记录均按 Workspace 隔离，且不保存任何密钥。
- 内容日历、素材包、审核中心、提醒中心可读取数据。
- 内容日历可以手动新增计划项、显示首月计划截止日期，并将计划项设为可执行、需审核或已完成。
- 素材包中心可以手动创建素材包结构、把文件项关联到已审核素材、推进文件项状态、自动更新素材包整体状态、提交 Web 审核，查看可交付性检查，并下载带交付检查、基础 PDF、XLSX、DOCX、TXT、关联素材和 manifest 的本地 ZIP 可交付文件包；manifest 包含策略、产品事实、内容计划、已审核素材和可交付性摘要。
- 项目详情和 `/b-agent` 可以下载项目工作台 JSON 快照，用于演示备份和复盘。
- 审核中心可以生成待审任务，并将通过/要求修改写回对应业务对象，也可以取消误生成任务。
- 提醒中心可以扫描项目缺口生成提醒，并把处理结果写入变更日志。
- 提醒中心可以手动创建提醒，关联当前 Workspace 下的项目，记录级别和截止日期。
- 数据复盘可以单条或批量录入并展示曝光、点击、转化、花费、CTR、点击转化率和单次转化成本。
- 主动提醒扫描可以基于已录入渠道表现生成低点击率、无转化和投放花费风险提醒。
- 数据复盘可以导出 Workspace 复盘 JSON 快照，便于周报沉淀、演示前备份和未来飞书归档。
- `lint`、`typecheck`、`test`、`build` 通过。
