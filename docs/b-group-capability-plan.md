# B 组 AI 内容增长 Agent 能力拆分

## 演示定位

B 组 Agent 是“AI 内容增长负责人”，面向新品品牌和多产品团队。比赛演示优先展示一条完整链路，而不是把所有后台页面都做满。

核心演示链路：

```text
中文输入产品
  → AI 提取产品事实
  → 用户确认事实
  → AI 推荐市场、客群、平台、渠道和内容方向
  → 用户用中文修改策略
  → 系统转换成结构化操作
  → 用户确认正式策略
  → 生成首月计划和第一份素材包预览
```

## 能力模块

### 1. Workspace 与项目底座

- 多 Workspace。
- 多项目。
- 多产品。
- Workspace 级数据隔离。
- 项目与产品多对多关系。

### 2. 项目启动顾问

- 通过中文问题引导用户介绍产品。
- 询问目标市场、平台、渠道和内容目标。
- 识别缺失信息并主动追问。

### 3. 产品事实提取

- 提取产品名称、核心卖点、目标场景、视觉限制。
- 区分“用户确认事实”和“AI 推测”。
- 真实产品图和官方 Logo 必须保留来源。

### 4. 策略推荐

- 推荐市场。
- 推荐客群。
- 推荐平台和渠道。
- 推荐内容方向。
- 每条建议必须给出可理解理由。

### 5. 自然语言结构化操作

示例：

```text
巴西不做 LinkedIn，新增 TikTok，下个月每周生成一次素材包。
```

系统应转换为：

- 删除 LinkedIn。
- 新增 TikTok。
- 修改素材包生成频率。
- 检查是否与正式策略冲突。
- 必要时请求人工确认。
- 保存变更日志。

### 6. 策略确认与版本

- AI 输出先是草稿。
- 人工确认后才成为正式策略。
- 正式策略必须有版本记录。
- 后续变更必须能追踪。

### 7. 内容日历

- 生成首月计划。
- 支持按周组织主题。
- 支持平台、内容形式和交付物分配。

### 8. 素材包生成

V1 目标素材包：

- 素材包说明 PDF。
- 内容排期 XLSX。
- 平台文案 DOCX。
- Hashtags TXT。
- TikTok 视频脚本 DOCX。
- 发布配文 TXT。
- 模板化海报图片。
- 海报文案 DOCX。
- 设计 Brief PDF。
- 品牌与合规检查 PDF。
- 最终 ZIP 打包下载。

### 9. 海报模板合成

- V1 使用真实产品图和官方 Logo。
- 采用图层结构：背景层、产品层、文字层、Logo 层、装饰层。
- 禁止 AI 重绘产品或改变产品结构。
- V1.5 再开放 AI 背景生成和画布扩展。

### 10. 审核、提醒、复盘

- 策略确认。
- 素材审核。
- 产品图、Logo、参数和合规检查。
- 基于时间、状态、缺口和机会生成提醒。
- 支持数据复盘。

### 11. 飞书可插拔连接

- 飞书只做通知、任务、简单审核和沉淀。
- 核心业务不依赖飞书。
- 飞书连接归属于 Workspace。
- 支持停用旧连接、换绑新组织和保存迁移记录。

## 是否拆成 Skill

当前建议先拆成系统内部能力模块，不立即拆成真正的 Codex Skill 插件。

适合未来沉淀为 Skill 的能力：

- 素材包文件生成。
- 海报模板合成。
- 图片生成供应商评测。
- 飞书连接迁移检查。
- 比赛演示数据生成。

## 下一步优先级

1. 保持 B 组仓库独立。
2. `/b-agent` 优先作为正式演示入口。
3. 先用模拟数据跑顺完整链路。
4. 再逐步把模拟数据替换为数据库、真实 AI、文件生成和飞书通知。
