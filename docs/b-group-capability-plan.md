# B 组 AI 内容增长 Agent 能力拆分

## 当前定位

B 组 Agent 是“AI 内容增长负责人”，面向新品品牌和多产品团队。当前目标已经从静态演示页推进到本地可用工作助手：先用可靠的规则型 Agent 和数据库工作流跑通事实、策略、计划、素材包、提醒和日志，再接真实 GPT、文件生成和飞书。

核心演示链路：

```text
中文输入产品
  → AI 提取产品事实
  → 用户确认事实
  → AI 推荐市场、客群、平台、渠道和内容方向
  → 用户用中文修改策略
  → 系统转换成结构化操作
  → 用户确认正式策略
  → 生成首月计划和第一份素材包预览
```

## 能力模块

### 1. Workspace 与项目底座

- 多 Workspace。
- 多项目。
- 多产品。
- Workspace 级数据隔离。
- 项目与产品多对多关系。

### 2. 项目启动顾问

- 通过中文问题引导用户介绍产品。
- 询问目标市场、平台、渠道和内容目标。
- 识别缺失信息并主动追问。

### 3. 产品事实提取

- 提取产品名称、核心卖点、目标场景、视觉限制。
- 区分“用户确认事实”和“AI 推测”。
- 真实产品图和官方 Logo 必须保留来源。

### 4. 策略推荐

- 推荐市场。
- 推荐客群。
- 推荐平台和渠道。
- 推荐内容方向。
- 每条建议必须给出可理解理由。

### 5. 自然语言结构化操作

示例：

```text
巴西不做 LinkedIn，新增 TikTok，下个月每周生成一次素材包。
```

系统应转换为：

- 删除 LinkedIn。
- 新增 TikTok。
- 修改素材包生成频率。
- 检查是否与正式策略冲突。
- 必要时请求人工确认。
- 保存变更日志。

### 6. 策略确认与版本

- AI 输出先是草稿。
- 人工确认后才成为正式策略。
- 正式策略必须有版本记录。
- 后续变更必须能追踪。

### 7. 内容日历

- 生成首月计划。
- 支持按周组织主题。
- 支持平台、内容形式和交付物分配。

### 8. 素材包生成

V1 目标素材包：

- 素材包说明 PDF。
- 内容排期 XLSX。
- 平台文案 DOCX。
- Hashtags TXT。
- TikTok 视频脚本 DOCX。
- 发布配文 TXT。
- 模板化海报图片。
- 海报文案 DOCX。
- 设计 Brief PDF。
- 品牌与合规检查 PDF。
- 最终 ZIP 打包下载。

### 9. 海报模板合成

- V1 使用真实产品图和官方 Logo。
- 采用图层结构：背景层、产品层、文字层、Logo 层、装饰层。
- 禁止 AI 重绘产品或改变产品结构。
- V1.5 再开放 AI 背景生成和画布扩展。

### 10. 审核、提醒、复盘

- 策略确认。
- 素材审核。
- 产品图、Logo、参数和合规检查。
- 基于时间、状态、缺口和机会生成提醒。
- 支持数据复盘。

### 11. 飞书可插拔连接

- 飞书只做通知、任务、简单审核和沉淀。
- 核心业务不依赖飞书。
- 飞书连接归属于 Workspace。
- 支持停用旧连接、换绑新组织和保存迁移记录。

## 是否拆成 Skill

当前建议先拆成系统内部能力模块，不立即拆成真正的 Codex Skill 插件。

适合未来沉淀为 Skill 的能力：

- 素材包文件生成。
- 海报模板合成。
- 图片生成供应商评测。
- 飞书连接迁移检查。
- 比赛演示数据生成。

## 下一步优先级

1. 保持 B 组仓库独立。
2. `/b-agent` 优先作为正式演示入口。
3. 已把模拟数据替换为数据库读取和本地规则型中文指令写入。
4. 下一步优先补真实素材 Asset、文件生成、模板化海报合成和 GPT Provider。
5. 飞书仍作为可插拔集成，等核心业务闭环稳定后再接。

## 当前已落地能力

- `ProductFact` 保存产品事实，并支持人工确认。
- 产品大脑可从产品说明、粘贴资料或已关联的 TXT/MD/CSV/JSON/DOCX/文本型 PDF 产品资料 Asset 生成待确认事实。
- `ProjectStrategy` 保存市场、客群、渠道、内容方向和素材包频率。
- `AgentTextProvider` 负责把中文指令转换为结构化操作，当前实现为 `local-rule`，后续 GPT 只作为新 Provider 接入。
- `agentCommandCapabilities` 集中维护 Agent 可执行能力、中文示例、写入表和人工审核要求，作为页面提示和未来 GPT 工具目录基础。
- `buildStrategyRecommendation` 当前根据项目关联产品事实和用户推荐请求生成本地规则型策略草案，后续可替换为 GPT 策略顾问 Provider。
- `AgentOperation` 保存中文指令转换后的结构化操作。
- `ChangeLog` 保存手工 CRUD、策略确认、指令应用、事实生成、计划生成、素材和提醒记录。
- `Asset` 保存真实产品图、官方 Logo、资料和参考图，并带审核状态、文件校验和上传限制。
- `ImageGenerationProviderConfig` 和 `ImageGenerationJob` 预留图片供应商评测与模板化合成任务；当前可生成内部 SVG 模板海报并写回 Asset。
- `IntegrationConnection` 和 `IntegrationMigrationRecord` 保存飞书占位连接、停用状态和迁移记录。
- `/projects` 支持中文 Brief 启动项目，一次创建项目、产品、关联、待确认事实、策略草案、对话和变更日志。
- `/b-agent` 在空 Workspace 下也支持用中文 Brief 启动第一个项目，避免首次使用必须跳转到项目中心。
- `/b-agent` 在已有项目时也支持用中文 Brief 创建新项目，便于连续管理多个市场或 Campaign 项目。
- `/b-agent` 支持用中文切换当前项目，例如“切换到蒙古项目工作台”，匹配范围限制在当前 Workspace，找不到目标时不改业务数据。
- `/b-agent` 支持用中文生成只读项目简报，例如“帮我看看这个项目现在怎么样”，汇总项目就绪度、策略、近期计划、最新素材包、开放提醒和建议动作。
- `/b-agent` 左侧中文指令可识别“创建/启动新项目”，并真实写入 Project、Product、ProjectProduct、ProductFact、ProjectStrategy、AgentConversation、AgentOperation 和 ChangeLog。
- `/b-agent` 左侧中文指令可给当前项目新增并关联产品；服务端会先在当前 Workspace 查找同名产品，避免重复创建。
- `/b-agent` 支持提交中文指令、确认正式策略、确认应用变更、修改项目状态、创建提醒、通过按钮或中文指令生成首月计划，并导出项目快照。
- `/b-agent` 右侧工作台顶部展示项目就绪度体检，复用今日工作台和项目详情的评分算法，让对话页也能看到阻塞项和下一步动作。
- `/b-agent` 支持根据当前项目产品事实生成策略推荐草案；已有正式策略时创建新的草案版本，等待人工确认。
- `/b-agent` 支持通过中文指令确认完整策略草案为正式策略；如果草案缺少目标市场、平台渠道或内容方向，会记录失败操作并要求先补齐。
- `/b-agent` 支持通过中文指令新增或校准待复核产品事实，也支持从粘贴的中文产品资料批量提取事实，并写入当前项目关联产品。
- `/b-agent` 支持通过中文指令确认当前项目关联产品的草稿/待复核事实，确认范围不会越过 Workspace 和项目。
- `/b-agent` 支持用中文录入单条渠道表现指标，也支持粘贴 CSV 或表格文本批量导入多条指标，直接沉淀到数据复盘并写入变更日志。
- `/b-agent` 支持用中文新增单条内容日历计划项，也支持粘贴 CSV 或表格文本批量导入计划项；每条计划包含周次、渠道、主题、标题、交付物、截止日期和状态。
- `/b-agent` 支持用中文完成项目提醒和内容日历计划项，匹配不到目标时不修改业务数据。
- `/b-agent` 支持把项目体检缺口转换为提醒，帮助用户把诊断结论变成可跟进待办。
- `/b-agent` 支持用中文创建指定周期素材包结构，并自动生成 V1 默认 11 项文件项。
- `/b-agent` 支持把素材包可交付性阻塞项转换为提醒，推动文件生成、真实产品图和官方 Logo 补齐。
- `/b-agent` 支持在用户明确确认后批量推进素材包文件项状态，并同步素材包整体状态。
- `/b-agent` 支持用中文提交素材包审核，自动进入 Web-first 审核中心并避免重复审核任务。
- `/b-agent` 支持用中文处理素材包审核通过或要求修改，审核决策会同步更新素材包状态和审核任务。
- `/b-agent` 支持补齐当前项目审核任务，覆盖策略草案、素材包、待审核素材和待复核产品事实。
- `/b-agent` 素材包预览会直接展示交付体检，按文件生成、文件审核、真实产品图、官方 Logo 和素材包审核给出分数、阻塞项和下一步动作。
- `/b-agent` 对正式策略变更会输出风险提示，覆盖渠道被清空、仍有计划使用被删渠道、内容方向为空、频率降低和项目暂停/归档。
- 今日工作台和项目详情会计算项目就绪度，按产品关联、产品事实、正式策略、计划、素材包、真实视觉素材、审核、复盘和提醒给出下一步动作。
- 项目详情支持把项目就绪度缺口生成项目提醒，帮助用户把体检结论转成可跟进事项。
- `/assets` 支持上传/下载素材、关联项目/产品、标记审核通过、同步审核任务和生成本地 SVG 模板海报。
- `/packages` 支持手动创建 11 项素材包结构、把文件项关联到已审核素材、推进文件状态、提交 Web 审核、查看可交付性检查，并下载带交付检查、基础 PDF、XLSX、DOCX、TXT、关联素材、人工审核清单与 manifest 的 ZIP 可交付文件包。
- `/integrations` 支持登记飞书占位连接、占位测试、停用旧连接和保存迁移记录。
- 内容日历、素材包中心、审核中心、提醒中心、数据复盘读取当前 Workspace 数据。
- 今日工作台会按待确认指令、审核任务、未审核素材、策略草案、素材包草稿和近期计划生成行动队列，并展示项目就绪度体检。
- 今日工作台会生成 Agent 工作简报，把素材包、近期内容计划、开放提醒和渠道表现聚合成中文重点进展、风险和下一步动作。
- 主动提醒扫描会结合近期渠道表现，识别点击率偏低、有点击无转化和有花费无转化等风险。
- 数据复盘支持单条/批量指标录入、CTR、点击转化率、单次转化成本和 Workspace 复盘 JSON 快照导出。

## 仍待补齐能力

- 真实 GPT 顾问式追问、事实抽取和策略推荐 Provider。
- PDF、XLSX、DOCX、TXT、PNG、ZIP 真实文件生成。
- 真实产品图 + 官方 Logo 的实际模板渲染输出。
- 外部平台表现数据导入和总结。
- Workspace 级真实飞书授权、测试连接、通知群和沉淀位置选择。
