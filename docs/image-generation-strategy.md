# 图片生成与视觉合成策略

## 核心结论

V1 的正式产品视觉不能完全交给生成模型自由生成。AI 图片模型可能改变产品比例、颜色、Logo、结构，甚至添加不存在的零件。这类错误在营销素材中属于品牌和合规风险，不能依靠模型自行保证正确。

因此 V1 采用“真实产品图 + 官方 Logo + 模板化合成”的方式：

- 产品层必须引用已审核的真实产品 Asset。
- Logo 层必须引用已审核的官方 Logo Asset。
- 可以裁切、缩放、定位、排版和添加阴影。
- 禁止 AI 重绘产品、改变产品结构或静默替换产品图。
- 生成结果必须进入审核流程后，才可进入正式素材包。

V1.5 再开放 AI 背景生成、产品主体锁定、光影融合和多尺寸智能延展。

## V1 图层结构

V1 模板化海报采用图层化结构：

- Background Layer：背景层，可以是纯色、渐变、上传背景或后续 AI 背景。
- Product Layer：产品层，必须引用已审核真实产品图。
- Text Layer：文字层，来自策略、平台文案或人工输入。
- Logo Layer：Logo 层，必须引用已审核官方 Logo。
- Decoration Layer：装饰层，可使用非产品装饰元素。

Product Layer 和 Logo Layer 必须保留素材来源，不允许图片模型重绘。

## 可插拔供应商

图片生成能力必须通过 `ImageGenerationProvider` 或等价适配器接入，不在页面、业务服务或数据库中写死某个模型或平台。

第一批候选供应商可以记录：

- OpenAI Image API
- Adobe Firefly

候选只表示“待测试”，不代表最终选择。最终供应商不能只根据宣传选择，必须使用我们的真实产品图、官方 Logo 和典型海报场景做样张测试。

## Workspace 级配置

后续应允许按 Workspace 配置不同图片供应商：

- 供应商名称。
- 模型名称。
- 可用生成模式。
- 成本与限额。
- 内容安全策略。
- API 密钥或凭证引用。

API 密钥只能保存在服务端环境变量，或未来的加密集成配置中，不得暴露到浏览器，不得提交到 Git。

## 生成任务与素材库

图片生成任务与普通文件 Asset 分离。建议后续模型：

- `Asset`：统一素材库，保存用户上传、生成产物和导出文件。
- `ImageGenerationJob`：图片生成任务，保存供应商、模型、输入、状态和错误。
- `ImageGenerationProviderConfig`：Workspace 级供应商配置。

生成结果如果通过审核，最终进入统一素材库。

生成元数据至少保存：

- `provider`
- `model`
- `promptVersion`
- `sourceAssetIds`
- `generationMode`
- `aspectRatio`
- `createdAt`
- `status`
- `error`

`generationMode` 至少预留：

- `template_composition`
- `background_generation`
- `image_edit`
- `image_expand`

## 产品主体锁定

正式产品视觉必须支持“产品主体锁定”概念：

- 真实产品图是可信源。
- AI 可以生成背景、氛围、节日场景、画布扩展和非产品装饰元素。
- AI 不得改变产品主体、Logo、产品名称、参数和关键结构。
- 如需光影融合，应以真实产品层为基准进行非破坏式处理。

## 样张评测标准

后续选型至少使用同一批真实产品素材测试：

1. 产品外观保持度。
2. Logo 保持度。
3. 是否增加不存在的零件。
4. 产品颜色和比例是否改变。
5. 背景真实感。
6. 产品与背景的光影融合。
7. 文字生成准确度。
8. 多语言文字效果。
9. 多尺寸输出能力。
10. API 稳定性。
11. 生成速度。
12. 单张成本。
13. 商业使用与内容安全规则。
14. 批量生成能力。
15. 失败后的可重试性。

## 输出分级

- A 级：产品和品牌准确，可进入审核。
- B 级：背景可用，但产品或排版需重新合成。
- C 级：产品失真，禁止进入正式素材包。

无论使用哪种图片模型，正式发布前都必须经过：

- 产品素材来源检查。
- Logo 检查。
- 产品名称和参数检查。
- 人工审核。

## 失败和降级策略

当图片生成失败或输出不达标时：

- 保留原始任务、错误信息和输入参数。
- 允许重试同一供应商。
- 允许切换供应商重新生成背景。
- 产品层和 Logo 层回退到真实 Asset。
- 模板合成始终作为稳定降级路径。
- C 级输出禁止进入正式素材包。

## 第一阶段实现状态

第一阶段只提供接口与文档预留：

- `ImageGenerationProvider` 抽象。
- `ImageGenerationMode`、`ImageGenerationMetadata`、`PosterLayerType` 类型。
- 产品主体锁定类型。
- 不调用真实图片生成 API。
- 不保存供应商密钥。
